# 关于我

> 我与我周旋久，宁作我。

我是知歌（Eurekaimer），统计学本科生，接下来会去中国科学技术大学继续学概率统计。大学前半段都在啃测度论、实分析和概率极限定理，还以为自己会一直做学术。真做了科研，见过为了凑指标硬写的论文，我就想回自己的书桌了。现在遇到问题，我更愿意翻原书、自己推一遍，能写代码就跑一遍。

## 从联机到 Linux

高一为了和朋友联机玩 Minecraft 和 Terraria，我第一次摸 Linux 服务器。大三为了复现论文，用一块外置 SSD 装了 Ubuntu，就这么入了坑。后来迷上 NixOS 的回滚；折腾久了，还是因为 FHS 的兼容问题换到 CachyOS。现在用 Niri、Neovim、Kitty、Ghostty 和各种 TUI，日常基本手不离键盘。开源最让我高兴的一点：别人做的东西我能接着改，我改完也能交回去。

## 我喜欢的百合

《Girls Band Cry》里井芹仁菜竖的中指，我记得特别清楚。山田尚子在《利兹与青鸟》里把放手拍得很轻，后劲却大。《终将成为你》把接纳自己这件事写得一点也不轻松。我也在长佩和晋江读七小皇叔、扶华和闵然。

## 这里写什么

用过 MkDocs，试过 Zensical，现在这个博客跑在 Astro 上。我在这里写百合，记键盘工作流和用大模型写代码踩过的坑，也复盘一些大学里没想通的事。我想慢慢写，不让推荐算法替我挑题。

概率、统计、深度学习和算法笔记在 [笔记站](https://www.eurekaimer.icu/notes)，随手记的东西在 [动态](/blog/moments/)。追番和游戏记录在 [Bangumi](/blog/bangumi/) 和 [Steam](/blog/steam/)。
